# Task 3: Generative AI, LLM Applications, AI Agents & Multi-Agent Systems

## Overview
This task covers the foundations of Generative AI and the concepts involved in building, evaluating and coordinating reliable LLM-powered applications and AI agents.

## Topics Covered
- Python for AI development
- AI, Machine Learning, Deep Learning and LLM fundamentals
- Prompt evaluation and LLM-as-a-Judge
- AI agents, tools and agent loops
- Agent instruction evaluation
- Context engineering and Retrieval-Augmented Generation (RAG)
- AI fluency and responsible AI use
- AI orchestration and workflow patterns
- Agent-to-Agent (A2A) communication and MCP

## Objective
Understand how to develop, evaluate and coordinate AI-powered applications, from basic LLM integration to tool-using agents and collaborative multi-agent workflows.

## Key Takeaway
Reliable AI applications require more than capable language models: they also need relevant context, clear instructions, systematic evaluation, controlled tool usage and responsible human oversight.
